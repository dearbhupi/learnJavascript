    Global Context

    • In javascript, when you run the code, it will create a global execution context. This is called global context.
    • In global context, you can access the variables and functions defined in the global scope.
    • it have two phases, first is memory allocation phase and second is code execution phase.
    • In memory allocation phase, it will allocate memory for the variables and functions defined in the global scope.
    • In code execution phase, it will execute the code line by line.

    this and window

  • In javascript, this is a keyword which refers to the object which is executing the current function.
  • In global context, this refers to the global object which is window in browser and global in node.js.

    difference between let, const and var

  • In javascript, var is function scoped and let and const are block scoped.
  • var can be re-declared and updated, let can be updated but not re-declared, const cannot be updated or re-declared.
  • var is hoisted and initialized with undefined, let and const are hoisted but not initialized.

    difference between == and ===

  • In javascript, == is used for comparison of values and === is used for comparison of values and types.
  • == is called loose equality operator and === is called strict equality operator.
  • == will convert the values to the same type before comparing them and === will not convert the values to the same type before comparing them.

      lexical scoping and dynamic scoping

    • In javascript, lexical scoping means that the scope of a variable is determined by its position in the source code and dynamic scoping means that the scope of a variable is determined by the call stack at runtime.
    • In lexical scoping, the scope of a variable is determined by its position in the source code and in dynamic scoping, the scope of a variable is determined by the call stack at runtime.

      difference between null and undefined

    • In javascript, null is an assignment value which means no value and undefined means a variable has been declared but has not yet been assigned a value.
    • null is an object and undefined is a type of undefined.
    • null is falsy and undefined is also falsy.

      difference between synchronous and asynchronous

    • In javascript, synchronous code is executed line by line and asynchronous code is executed in parallel.
    • Synchronous code is blocking and asynchronous code is non-blocking.
    • Synchronous code is executed in the order it is written and asynchronous code is executed in the order it is completed.
    • Synchronous code is executed in the main thread and asynchronous code is executed in the event loop.

      difference between call, apply and bind

    • In javascript, call and apply are used to invoke a function with a specific this value and arguments and bind is used to create a new function with a specific this value and arguments.
    • call and apply are used to invoke a function immediately and bind is used to create a new function which can be invoked later.
    • call and apply are used to invoke a function with a specific this value and arguments and bind is used to create a new function with a specific this value and arguments.

      what are functions in javascript

    • In javascript, functions are first class citizens which means that they can be assigned to variables, passed as arguments to other functions and returned from other functions.
    • Functions are used to create reusable code and to create higher order functions.
    • Functions can be defined using function declaration, function expression and arrow function.

      what are higher order functions in javascript

    • In javascript, higher order functions are functions which can take other functions as arguments and can return other functions as return values.
    • Higher order functions are used to create reusable code and to create function composition.
    • Higher order functions can be defined using function declaration, function expression and arrow function.
